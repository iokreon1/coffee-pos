# Coffee Shop POS

Sistem Point of Sales (POS) manajemen penjualan dan operasional harian yang dirancang khusus untuk bisnis coffee shop skala menengah.
Sistem ini dibangun menggunakan backend berbasis Go (Golang) dan MySQL.

## API Documentation
Cek `API_CONTRACT.md` untuk spesifikasi lengkap endpoint API.
Cek `postman_collection.json` untuk testing di Postman.
